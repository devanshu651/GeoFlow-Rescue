# Digital Elevation Model (DEM) Data

This directory is intended for storing Digital Elevation Model (DEM) data.

## What is DEM data?
A Digital Elevation Model (DEM) is a 3D computer graphics representation of elevation data to represent terrain. It represents the continuous variation of relief over space.

## Format
We will use the **GeoTIFF** format for storing DEM data in this project. GeoTIFF is a public domain metadata standard which allows georeferencing information to be embedded within a TIFF file.

## Usage
The DEM data represents elevation values of terrain at specific points. In this project, this data will be utilized for:
- Slope analysis
- Flow direction calculation
- Water accumulation modeling
- Flood simulation
- Landslide-risk analysis
